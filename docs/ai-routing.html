AIの使い分け

どの頭脳に考えさせるか

Codex（GPT）

① 先に使う・量の多いコード
  • まとまった実装・リファクタ
  • テスト作成・コードレビュー
目安：複数ファイル・数十行以上

Claude

② 仕上げ・判断
  • Codex の結果の確認・手直し
  • 日本語の文章・事業判断
  • 数行の小さな修正
迷ったら Claude が自分でやる

Gemini

③ ここぞの時だけ
  • 画像・図・アイコン
  • 数万字以上の資料の要約
  • GA データの分析
普通の文章・コードには使わない

Gemini アプリ（Pro）

④ あなたが手で使う
  • 手で作る画像・動画
  • Deep Research
  • NotebookLM
必要な時は Claude が勧める

APIの使い分け

お金・回数の枠をどこで使うか

Gemini API

使う（gask 経由だけ）
  • 無料枠：1日 約20回/モデル
  • 1日 200万トークン・画像10枚で自動停止
  • 数字は生データと自動照合（⚠️ は使わない）
キーは Mac のキーチェーン／クラウドは Network secrets

Claude・Codex

API は使わない（契約プランの枠）
  • Claude Code ＝ Claude の契約
  • Codex CLI ＝ ChatGPT の契約
  • 相互レビュー・高い推論レベルで質を上げる
  • API キーの従量課金はしない
枠内なら質のために使い切る（月で余らせない）

Google AI Pro

API の枠は増えない
  • Pro・5TB は API とは別勘定
  • 枠を増やすなら AI Studio で支払い設定
  • 上限で止まったら勝手に延長しない
延長・課金はあなたが決める

CLIの使い分け

Claude Code がどのコマンドで動かすか

codex

実装・レビュー
  • 実装 -s workspace-write
  • レビュー -s read-only
  • どちらも codex exec・推論 high
Codex↔Claude で互いにレビュー

gask

Gemini を呼ぶ唯一の入口
  • gask image 画像
  • gask summarize 大量資料
  • gask analyze GA
gemini -p は直接呼ばない

agy（Antigravity）

事業判断のクロスチェック
  • agy --mode plan
  • 大事な判断を Gemini で再確認
Pro のログインで動く

gh・netlify など

道具（AI ではない）
  • gh GitHub 操作
  • netlify サイト公開
公開・送信は事前に確認
どれを使っても、最後に確認して報告するのは Claude Code
